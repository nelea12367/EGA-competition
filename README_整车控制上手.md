# DM-MC02 整车控制上手说明

本固件在原有四麦轮底盘基础上增加：DM430 步进大臂、ID 5 C610/2006 小臂、腕部 DS3218MG 舵机、爪子舵机。**首次调试必须让车轮悬空，机械臂附近不得站人。**

## 1. 默认信号分配

| 功能 | DM-MC02 信号 | 外接设备 |
|---|---|---|
| 大臂步进脉冲 | PD15 / TIM4_CH4 | 6N137 输入 1 -> DM430 `PUL-` |
| 大臂方向 | PD14 | 6N137 输入 2 -> DM430 `DIR-` |
| 大臂使能 | PE14 | 6N137 输入 3 -> DM430 `ENA-`（默认固件不主动驱动 ENA） |
| 腕部 PWM | PB14 / TIM12_CH1 | DS3218MG 信号线 |
| 爪子 PWM | PB15 / TIM12_CH2 | 爪子舵机信号线 |
| 小臂 | CAN ID 5 | C610 + 2006，控制帧 `0x1FF` |

所有信号地、舵机 5--6V 供电地、6N137 输入侧地均须按各模块要求正确连接；**舵机电源不得由 STM32 的 3.3V 或 GPIO 供给。**

## 2. 6N137 与 DM430

购买版本：4 通道、3.3V 输入、7--24V 供电、三极管集电极输出。输入侧按“共阴极/PNP 输入”接法：DM-MC02 GND 接信号输入公共负端，PD15/PD14/PE14 分别接输入 1/2/3。

输出侧必须以卖家提供的端子图为准，且需确认是 **NPN 开集电极低端输出**。确认后：

```text
中心板 +24V -> 6N137 电源正、DM430 PUL+/DIR+/ENA+、DM430 +VDC
中心板  0V -> 6N137 电源负/输出 COM、DM430 GND
OUT1 -> DM430 PUL-
OUT2 -> DM430 DIR-
OUT3 -> DM430 ENA-
```

DM430 的电机线接 A+/A-/B+/B-；供电范围 12--32V。先按步进电机铭牌设置 DM430 工作电流和细分，首测使用较低电流。固件将 PUL 频率限制在 10kHz。

## 3. 遥控逻辑

`Core/Inc/vehicle_config.h` 是唯一需要按实际遥控器和机构修改的配置文件。

| 条件 | 行为 |
|---|---|
| CH7(SWA) 未到使能档 | 所有车轮电流归零、步进停止、2006 电流归零 |
| CH8(SWB) 非机械臂档 | 底盘模式，沿用原有麦轮摇杆映射 |
| CH8(SWB) 为机械臂档 | 底盘强制停止，进入机械臂模式 |
| 机械臂档 + 使能 + 三个机械臂摇杆回中 500ms | 将人工摆好的收臂姿态记为软件零点 |
| 软件零点成功后 | CH3 控大臂、CH4 控小臂、CH1 控腕部、CH9 控爪子张/停/合 |

无原点开关时，断电、堵转、丢步或手动掰动机械臂后，必须重新人工摆回统一收臂姿态，再进机械臂模式完成 500ms 参考确认。

## 4. 上电顺序

1. 不接 DM430/C610/舵机，只烧录并测 PB14/PB15 的 50Hz PWM、PD15 的低频脉冲。
2. 单独接 DM430，机械臂脱开负载或留足空间，低电流验证 CH3 两个方向。
3. 单独接两路舵机，先把 `vehicle_config.h` 的脉宽窗口调到实测安全范围。
4. 只接 ID 5 的 C610/2006，确认收到 `0x205` 反馈后再做小电流测试。
5. 车轮悬空时验证底盘 ID 1--4 与小臂 ID 5 同总线工作。
6. 全部通过后才允许低速落地测试。

## 5. 构建

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1 `
  -ToolchainBin 'D:\stm32cubeide\STM32CubeIDE_2.2.0\STM32CubeIDE\plugins\com.st.stm32cube.ide.mcu.externaltools.gnu-tools-for-stm32.14.3.rel1.win32_1.0.100.202602081740\tools\bin' `
  -OutName DM_MC02_Vehicle
```

产物为 `build\DM_MC02_Vehicle.hex`。构建成功不表示接线与机构方向已经安全；必须按第 4 节逐项台架验证。
