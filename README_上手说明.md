# 麦轮底盘固件（DM-MC02 / STM32H723VGT6）· 上手说明

> 遥控：FS-i6 + FS-iA10B　电机：4×M3508 + 4×C620　总线：FDCAN2 @1Mbps
> 工程：`dm_mc02_chassis/`（用 STM32CubeIDE 打开就能编译，也可以用 `build.ps1` 命令行编译）

---

## 0. 30 秒版本

1. CubeIDE 打开 `dm_mc02_chassis` → Build → 烧录。
   不想编译的话，`firmware/` 里已经放好三个编好的 hex：

   | 文件 | 什么时候烧 |
   |---|---|
   | `DM_MC02_Chassis_IDPROBE.hex` | **第一步**：测四块 C620 的 ID（见第 4.1 节） |
   | `DM_MC02_Chassis_SELFTEST.hex` | **第二步**：单轮点动，确认位置和转向（见第 5 节） |
   | `DM_MC02_Chassis.hex` | **第三步**：正常开车 |

2. 上电：灯红→绿→蓝闪三下 = 灯正常；之后**绿常亮** = 可以开车，**红闪** = 没收到遥控，**紫闪** = 电机 CAN 没通。
3. 左摇杆上下 = 前进/后退，左摇杆左右 = 左右平移，右摇杆左右 = 原地转。
4. 车不动先看灯，再看第 8 节的排查表。

## 1. 和你原来那份 `DM_MC02_Test` 的区别

| 项 | 原例程 | 现在 |
|---|---|---|
| 遥控协议 | 只认 SBUS（100k、8E2、反相） | **iBUS / SBUS 自动识别**，插哪个口都能跑 |
| 通道映射 | CH7/CH9 两个开关都到位才使能，FS-i6 只有 6 通道 → 永远不使能 | 按 FS-i6 6 通道映射，开关可选（默认不要求） |
| 失联 | 有超时，但恢复后会直接接着跑 | 超时 120ms 立即归零，**必须摇杆回中**才能再动 |
| 电机掉线 | 四轮没全在线就静默不出力，看不出原因 | **紫色闪灯**报警，一眼看出是 CAN 的问题 |
| 解算 | 归一化 -1~1 直接当轮速 | 真·麦轮解算（轮半径 / 半轴距 / 半轮距），单位 m/s |
| 速度环 | 纯 P | PI + 抗积分饱和 + 电流斜坡 |
| 起步 | 上电就能动 | 上电必须摇杆回中 200ms |
| 台架标定 | 没有 | **电机 ID 探测**（灯闪 N 下 = 这块是 N 号）+ **单轮点动自检**（确认位置和转向） |

### 原例程"灯绿但轮子不动"最可能的三个原因

1. **四块 C620 的 ID 没改**（出厂都可能是 1 号）→ 四路反馈全挤在 0x201，代码判断"四个电机没全部在线"就一帧电流都不发，灯还是绿的。**这是最常见的一条，先查它。**
2. CAN_H / CAN_L 接反，或者没共地、没 24V、没有 120Ω 终端电阻 → 一帧反馈都收不到。
3. 接收机实际输出的是 **iBUS**，而原例程只认 SBUS → 那就连灯都不该是绿的（应该是红）。你能看到绿灯说明遥控在动，所以更偏向第 1、2 条。

## 2. 接线对照表（你说已经接好了，对照一遍就行）

| 信号 | 板子引脚 | 说明 |
|---|---|---|
| 接收机信号（iBUS/SBUS 那个 3 针口） | **PD2**（丝印 UART5_RX / RX5） | 只接信号线这一根 |
| 接收机 GND | GND | **必须和主板共地**，不共地会时好时坏 |
| 接收机 VCC | 5V | FS-iA10B 支持 3.5~9V |
| C620 CAN_H | 板子 CAN_H | H 对 H，**不要交叉** |
| C620 CAN_L | 板子 CAN_L | |
| C620 GND | 板子 GND | 共地 |
| C620 电源 | 24V（6S） | 12V 带不动 M3508 |
| 总线两端 | 120Ω × 2 | 台架线短可以先不装，但一旦丢帧先补上 |

板子这边用到的外设（原例程就是这样配的，不用改 CubeMX）：

```
FDCAN2 : PB5 = RX, PB6 = TX        -> 板上 CAN 收发器 -> CAN_H / CAN_L
UART5  : PD2 = RX, PB13 = TX       -> 接收机信号线
SPI6   : PA5 = SCK, PA7 = MOSI     -> 板载 WS2812 状态灯
```

## 3. 遥控器（FS-i6 + FS-iA10B）

1. **先对码**：遥控器 `System → RX Setup → RX Bind`，接收机灯常亮 = 对上了。
2. **输出模式**：如果菜单里有 `Output mode / 输出模式`，选 **iBUS** 或 **S.BUS** 都行，**别选 PWM**。
   没有这个菜单也不用管——固件会自动在 iBUS / SBUS 之间找。
   如果接收机只输出 PWM（每个通道一根线），板子一个字节都收不到，灯会一直红闪。
3. 通道分配（FS-i6 默认，Mode 2）：

| 通道 | 摇杆/开关 | 本固件用途 |
|---|---|---|
| CH1 | 右摇杆左右 | 原地转 wz |
| CH2 | 右摇杆上下 | **不用** |
| CH3 | 左摇杆上下（油门棘轮，不回中） | 前进后退 vx |
| CH4 | 左摇杆左右 | 左右平移 vy |
| CH5 | SWA | 使能开关（默认不用，见 `CHASSIS_REQUIRE_ARM`） |
| CH6 | SWB | 快/慢档（拨到 DOWN = 慢速 35%） |

> 如果推杆方向和车实际动作不一致，**不要改接线**，改 `chassis_config.h` 里的
> `RC_SIGN_FORWARD / RC_SIGN_STRAFE / RC_SIGN_ROTATE`（±1）或 `CHASSIS_MOTOR_REVERSED_MASK`。

## 4. C620 ID：先拨，再验（⚠ 必做）

- 代码假定：**ID1 = 左前，ID2 = 右前，ID3 = 左后，ID4 = 右后**，控制帧 0x200，反馈 0x201~0x204。
- 每块 C620 侧面有一个 4 位拨码开关（丝印 1 2 3 4），前 3 位是二进制 ID，第 4 位不用：

| ID | 1 | 2 | 3 |
|---|---|---|---|
| 1 | OFF | OFF | OFF |
| 2 | ON | OFF | OFF |
| 3 | OFF | ON | OFF |
| 4 | ON | ON | OFF |

> 不同批次丝印可能不同，**以电调外壳上印的那张表为准**。拿不准就别猜，用下面的探测法。

### 4.1 验证 ID（不用 CAN 分析仪）

1. 打开 `chassis_config.h`，把 `CHASSIS_ID_PROBE_ON_BOOT` 改成 `1`，编译烧录。
2. **只接一块电调**（断电再接线），上电。
3. 板子只发 0 电流、只听反馈，**绿灯每 2 秒闪一轮，闪 N 下 = 这块是 N 号**；
   红慢闪 = 一块都没看见（CAN 没通/没 24V/线错）。
4. 四块挨个测一遍，记下每块的真实 ID，然后把拨码拨成 1/2/3/4。
5. 四块都接回去，`CHASSIS_ID_PROBE_ON_BOOT` 改回 `0`，再烧一次。

四块都不改拨码（出厂常常全是 1）时，现象就是：**遥控正常、灯是绿的、轮子一动不动**。

改完 ID 后，用第 5 节的自检确认"ID ↔ 物理位置"。

## 5. 轮序标定（单轮点动自检）

底盘**架空、轮子悬空**（必须！）：

1. 打开 `Core/Inc/chassis_config.h`，把 `CHASSIS_SELFTEST_ON_BOOT` 改成 `1`。
2. 编译、烧录、上电。
3. 会看到 1→2→3→4 号电机依次转 1.2 秒，灯的颜色对应：
   蓝 = 1 号，青 = 2 号，紫红 = 3 号，白 = 4 号。
4. 记下"哪只轮子在转""往哪个方向转"，填这张表：

| 电机 ID | 实际位置（左前/右前/左后/右后） | 正电流时转向（面对车头：顺时针/逆时针） | 和期望一致？ |
|---|---|---|---|
| 1 号（0x201） | | | |
| 2 号（0x202） | | | |
| 3 号（0x203） | | | |
| 4 号（0x204） | | | |

5. 位置装错的，**改接线不如改映射**：把 `chassis.c` 里 `wheel_linear[]` 的四个下标按实际位置对调
   （保持"左前/右前/左后/右后"的顺序）。
6. 转向反了的，把 `CHASSIS_MOTOR_REVERSED_MASK` 对应 bit 置 1（bit0=1号 … bit3=4号），
   例如 2 号反了 → `0x02`。
7. 测完把 `CHASSIS_SELFTEST_ON_BOOT` 改回 `0`，再烧一次。

## 6. 状态灯含义

| 灯 | 含义 | 下一步 |
|---|---|---|
| 红闪（200ms） | 收不到遥控 | 查接收机供电/对码/信号线是否在 PD2/输出模式是否 PWM |
| 白闪（400ms） | 遥控正常，但摇杆没回中 | 松开摇杆，1 秒内自动变绿 |
| 橙常亮 | 遥控正常，但不允许出力 | 开关没拨对（`CHASSIS_REQUIRE_ARM=1` 时）或还没回中 |
| 绿常亮 | 可以开车 | 推杆 |
| 紫闪（100ms） | 有电机 CAN 反馈掉线 | 查 24V / CAN_H/L / 共地 / 120Ω / C620 拨码 ID |
| 蓝 / 青 / 紫红 / 白 | 自检正在转 1/2/3/4 号电机 | — |
| 绿闪 N 下 + 停顿 | ID 探测模式：这块电调是 N 号 | 见 4.1 节 |
| 红慢闪（ID 探测时） | 一块电调都没回话 | CAN 没通 / 没 24V / 线接错 |

## 7. 参数都在 `Core/Inc/chassis_config.h`

按这个顺序调，不要一上来就调 PID：

1. **几何**（`CHASSIS_WHEEL_RADIUS` / `CHASSIS_HALF_WHEELBASE` / `CHASSIS_HALF_TRACK`）
   轮子半径实测：地上滚 10 圈量距离 L → `R = L / (10 × 2π)`。
2. **方向**（`CHASSIS_MOTOR_REVERSED_MASK`、`RC_SIGN_*`）——用自检和第 5 节确认。
3. **限速**（`CHASSIS_MAX_VX/VY/WZ`）——首版 1.5 / 1.0 / 3.0，跑顺了再往上加。
4. **手感**（`CHASSIS_ACC_*`、`RC_EXPO`、`RC_DEADBAND`）——起停"窜"就把加速度调小，摇杆太灵就把 expo 调大。
5. **最后才是速度环**（`CHASSIS_SPEED_KP/KI`、`CHASSIS_CURRENT_LIMIT`）。

改完建议先用 `CHASSIS_CURRENT_LIMIT 4000` 在台架上试，再放开到 6000+。

## 8. 故障排查

| 现象 | 最可能的原因 | 怎么办 |
|---|---|---|
| 灯红闪，推杆没反应 | 接收机没供电 / 没对码 / 信号线没插在 PD2 / 输出模式是 PWM | 万用表量接收机 5V；重新对码；确认菜单里是 iBUS 或 SBUS |
| 灯白闪不变绿 | 摇杆没回中（或某个通道中值不对） | 松开摇杆；仍不行就改 `RC_SBUS_CENTER/SPAN` 或 `RC_IBUS_CENTER/SPAN` |
| 灯绿但轮子不动 | C620 ID 重复 / 没 24V / CAN 接反 / 没共地 | 见第 4 节；量 C620 电源；万用表量 CAN_H-CAN_L 之间约 60Ω（两个 120Ω 并联） |
| 灯紫闪 | 有一路或多路反馈没回来 | 同上；单独拔掉其它三块只留一块，看是否只有 1 号能通 |
| 车往一边跑、松杆不停 | 遥控中值不对（SBUS 用 992，这台可能用 1500） | 改 `RC_SBUS_CENTER 1500` / `RC_SBUS_SPAN 500` |
| 前进变后退、左转变右转 | 符号反了 | 改 `RC_SIGN_*` 或 `CHASSIS_MOTOR_REVERSED_MASK` |
| 一推杆就窜、刹车点头 | 加速度太大 | 调小 `CHASSIS_ACC_LINEAR` / `CHASSIS_CURRENT_SLEW` |
| 跑起来轮速跟不上、发软 | 电流限幅太低或 PID 太软 | 提高 `CHASSIS_CURRENT_LIMIT`，再调 `CHASSIS_SPEED_KP` |

---

## 9. 台架安全（第一次上电务必）

- 底盘**架空**，四个轮子悬空能自由转。
- 手边能立刻断电（拔 XT60）。
- 轮子附近不要有线束、手指、纸。
- 第一次只做"单轮点动自检"，确认方向后再落地。

---

## 10. 下一步（想往比赛底盘走的话）

- **失联/掉线故障注入**：关遥控器、拔一根 CAN 线，确认车立刻停、灯报警、恢复后必须回中。
- **微调档**：现在 CH6 拨到 DOWN 是 35% 速度，可以再单独做一档 `CHASSIS_SLOW_SCALE 0.15` 用来对准得分区。
- **爬坡**：`CHASSIS_CURRENT_LIMIT` 提到 12000 并限时，配合低速档。
- **对外接口**：3 号（机构）会要 `Chassis_LockMotion()` 之类，需要时在 `chassis.c` 里加，别改驱动层。
