# 机械臂抖动 / 下坠 排查与整定（不改线版）

现象（2026-11-22 实测）：轮子正常、爪子能动（张开偏慢），**小臂（肘）和腕关节一直抖、无法稳定控制**，
**往下放的时候被自重带着快速掉下去**。

**本次改动全部在固件里，一根线都没有动。** 下面所有做法都假设电路保持现状。

## 1. 现象 → 原因

| 现象 | 直接原因 | 机理 |
|---|---|---|
| 腕（C610+2006）一直嗡嗡抖 | 位置环是**纯 P，Kp=4500** 过大 | 1° 误差就输出约 90 原始电流。配上减速箱齿隙和静摩擦，误差符号在 0 附近来回翻 → **bang-bang 极限环**，就是听到的嗡嗡声 |
| 腕往下放时掉得很快 | 没有重力前馈，只靠 P 顶 | 目标往下走，重力帮忙加速，实际角超到目标前面，误差反向，但刹车电流上限只有 2500（5A），重力矩超过就直接掉 |
| 一切到跑车模式腕就塌 | `VehicleControl_Update` 在底盘模式里把 2006 电流清零 | 机械臂有自重，电流一清就自由落体 |
| 大臂停住后自由下坠 | ① 驱动器 ENA 悬空 → 使能状态看驱动器自己；② 脉冲频率太高 → 重力负载下丢步 | 直驱大臂时 **转矩随脉冲频率下降**，1000Hz 已经能吃满余量，一丢步转子就打滑，看着像"啪"掉一截 |
| 小臂（DS3218MG 舵机）一直抖 | 舵机在**重力矩接近或超过额定力矩**时反复过冲；或指令顶到机械行程；或 5V 供电跌落 | 舵机内部是模拟位置环，负载一大就在目标附近来回找，表现为持续抖 + 发热 |
| 爪子张开有延迟、闭合不明显 | 速率 90°/s，60° 行程要 0.67s；张开要克服弹簧 | 闭合有弹簧帮忙所以"不延迟"，张开全靠舵机所以慢 |

## 2. 这次改了哪些代码

| 文件 | 改动 | 原因 |
|---|---|---|
| `Core/Src/arm_2006.c` | 纯 P 改为带 Kd 阻尼、位置死区、电流斜率限幅与重力前馈接口的控制；**首次上机 Ki=0、限流 2500**；**0x1FF 从 1kHz 降到 250Hz 发送** | 先以保守电流验证方向和 PD 稳定性，再单独整定积分；省总线给 0x200 |
| `Core/Src/vehicle_control.c` | 底盘模式下机械臂**就地抱死**（步进保电、2006 继续跑位置环）；步进改成**软停**（先降频再断脉冲） | 原来切模式就把 2006 电流清零、把脉冲硬切断，两个动作都会让臂塌 |
| `Core/Src/arm_stepper.c` | 加/减速分开（加速 3000、减速 3000 Hz/s）；停脉冲**不断使能**；力停止也保持通电 | 原来 15000Hz/s 相当于 66ms 从 0 冲到 1000Hz，起停瞬间步进电机最容易丢步 |
| `Core/Inc/vehicle_config.h` | `MAX_HZ 1000→350`、首次上机 `CURRENT_MAX` 保持 2500、爪子 90→200°/s、新增 `HOLD_TORQUE`/`HOLD_ARM_IN_DRIVE`/`SEND_PERIOD_MS` | 见下 |
| `Core/Src/servo_pair.c` | 脉宽没变就不重写 CCR | CCR 无预装载，运行中改写会截断当前周期脉冲 |
| `Core/Src/rc_input.c` | 摇杆量加一阶低通（约 20ms） | 接收机每帧几个计数的抖动会被位置环放大成可见抖动 |
| `Core/Src/tim.c` | TIM1/TIM2 预分频 **274→263** | 见第 3 节 |

编译结果：`build\DM_MC02_Vehicle.elf`，text 30968 B。

### 关于 274→263

轮子能转 ⇒ CAN 通了 ⇒ C620 只认 1.000 Mbps，24 个 tq（1+18+5）反推 **HSE = 24MHz** ⇒
PLL = 24/2×22 = **264MHz** ⇒ TIM1/TIM2 内核 264MHz。
原来 274 分频是按 275MHz 算的，实际给出 **48Hz**、脉宽整体偏长 4.17%（1100µs 变 1146µs）。
改成 263 → 正好 1.000MHz → 50.00Hz，CCR 就是微秒数。

> 副作用：舵机中位和端点整体挪 3~4°，上电后重新确认小臂和爪子的中位。

## 3. 不改线，靠这三件事治"掉下去"

### ① 降脉冲频率（`VEHICLE_STEPPER_MAX_HZ 1000→350`）

步进电机的**转矩随转速下降**是硬约束。直驱大臂、端部还有机械臂自重的情况下，
1000Hz 很可能已经超出该转速下的可用转矩，一推就失步 → 转子打滑 → 看起来"突然掉一截"。

现在上限 350Hz。如果还是掉，**继续往下压到 200、150**，一格一格试，
找"不丢步"的最高频率，再往回调 20% 当工作点。

### ② 起停变缓（`ACCEL/DECEL 15000→3000 Hz/s`）

原来 66ms 内从 0 冲到 1000Hz，起停瞬间是最容易丢步的时刻。
现在 350Hz 用大约 0.12s 加上去，起停都平滑。同时**软停**：摇杆回中时先降频到 0 再断脉冲。

### ③ 不再断电

- 停脉冲后继续让驱动器通电（`HOLD_TORQUE 1`），靠静力矩顶住重力；
- 切到跑车模式也不释放（`HOLD_ARM_IN_DRIVE 1`），机械臂就地抱死。

> 注意：DM430 的 `ENA+`/`ENA-` 现在是悬空的，**软件驱动 PE14 对它无效**。
> 大多数驱动器悬空默认"使能"，所以力矩本来就在；但如果你的这块默认"脱机"，那它就没有保持力矩，
> 这种情况只能靠第 4 节的机械办法，或者——如果你愿意动那一根线——把 ENA− 接到 GND 即可永久使能（不需要接单片机）。

### ④ 不改线也能动的两个硬件旋钮（不是接线，是驱动器上的拨码）

- **工作电流**：DM430 上的拨码/电位器，按电机铭牌调，首测别低于额定的一半。电流越大保持力矩越大。
- **细分**：细分调大（例如 1/16）让每一步更小、运行更平滑，同样是 350Hz 脉冲，转速更低但更不容易丢步。
  细分变了，`MIN/MAX_PULSE`（现在是 ±12000）对应的机械行程也会变，记得重新量。

## 4. 如果降速之后还掉，那就是力矩不够，只有机械办法

```
重力矩 = 质量(kg) × 9.8 × 质心到关节的水平距离(m)
```

拿这个数对比执行器额定（DS3218MG 约 2.0 N·m@6.8V；步进看型号）。
**超过额定 60% 软件怎么调都没用**，只有三条路，都不涉及电路：

1. **加弹簧**：小臂拉一根拉簧吊到大臂上，最便宜有效，能把重力矩抵掉一大半；
2. **加配重**：在大臂根部反向配重；
3. **缩短力臂**：把重的东西往关节方向挪。

## 5. 台架验证顺序

1. **先量 PE9**（TIM1_CH1）：应该是**正好 20.00ms**。量到 20.8ms 说明还在按 275MHz 跑。
2. **只接腕部（ID5）**，臂垫住：上电 → SWB 下 → 三轴回中 0.5s 记零点 → 推 CH1 前后走。
   松杆后应该**静止不抖**；还有轻微嗡嗡就把 `VEHICLE_LOWER_ARM_KP` 减到 600 再试。
3. **只接大臂步进**：推摇杆看**最低速能不能持续走**、停住后**会不会自己往下滑**。
   滑 = 丢步或没保持力矩 → 回到第 3 节压频率。
4. **只接小臂舵机**：把 `VEHICLE_WRIST_MIN_DEG/MAX_DEG` 先缩到实际安全角度的一半，
   慢慢放开找到"不顶死、不抖"的窗口，再写回配置。
5. 三个单独通过后再合体。

## 6. 安全提醒

- SWA 拨到禁用会走 `VehicleControl_ForceStop()`，把 2006 电流和步进脉冲全部切掉 →
  **举着的臂会掉下来**。调试时手别在臂下方，或者先落地再拨。
- 需要的话可以加"禁用时保持 2006 电流 200ms 再释放"的掉电抱闸，说一声。
